# 官网三端精修 · 2026-09-28

实现用户确认的首页升级预览，保留原有暖米色、品牌图像、藏品内容及图录素材。

- 首页：缩短首屏；统一栏目边界；展览增加直达电子图录入口；四件精选藏品先显示名称、后显示年代和状态；接入已发布文章的阅读入口。
- 手机：136px Logo、44px 导航触控区；藏品横向浏览，保留下一件的视觉提示。
- iPad：竖屏横向浏览，一屏两件并露出下一件；宽度达到 1024px 的横屏使用四列。1024×1366 竖屏仍横向浏览。
- 电脑：精选藏品四列并排；藏品图像完整等比显示，不改原图。
- 全站：中文标题使用思源宋体衍生子集，英文名称使用 Source Serif 4；统一适度的标题尺度与行距。文章正文、藏品资料、图录翻页与后台业务逻辑保留。
- 性能：仅首屏图片优先加载；精选图按实际显示宽度请求；字体分段按需加载；取消页面内容从完全透明开始的入场动画。
